# Cookie Clicker (PWA + APK pelo GitHub)

1. Crie uma conta e um repositório novo (público) em github.com
2. Add file > Upload files: envie TODOS os arquivos desta pasta (menos este LEIA-ME, se quiser) e faça o Commit
3. Abra o arquivo build.yml > lápis (editar) > no nome do arquivo escreva `.github/workflows/build.yml` > Commit
4. Settings > Pages > Source: GitHub Actions
5. Aba Actions: espere o "Build" ficar verde (uns 5 a 8 minutos)
6. APK: aba Releases > "Cookie Clicker APK" > baixe app-debug.apk
7. PWA: o link aparece em Settings > Pages (https://SEUUSUARIO.github.io/NOMEDOREPO/)
